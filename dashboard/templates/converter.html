🔧 Como usar o .gguf no celular (Android)

① Instale o Termux (F-Droid) e compile o llama.cpp:

pkg install -y git cmake python clang
git clone https://github.com/ggerganov/llama.cpp
cd llama.cpp && mkdir build && cd build
cmake .. -DCMAKE_BUILD_TYPE=Release && cmake --build . --config Release -j4

② Mova o .gguf baixado para uma pasta acessível, ex.: ~/downloads/rigelslm_Q4_K_M.gguf

③ Rode o chat local:

cd llama.cpp/build/bin
./llama-cli -m ~/downloads/rigelslm_Q4_K_M.gguf -p "Olá!" -n 128

💡 Em celular fraco, prefira o rigelslm_Q4_K_M.gguf (36 MB, Q4) — roda bem em hardware modesto.
