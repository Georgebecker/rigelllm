❓ Perguntas rápidas

O treino TXT trava mostrando menu? Use --no-interactive SEMPRE (ou inicie pelo dashboard).

O dashboard não recarrega mudanças? O --reload desta máquina não recarrega → reinicie o servidor.

GGUF decodifica vazio no Ollama? Bug conhecido → use o modelo PyTorch local (modelo.pt) no chat.

Quero ver o que cada script faz? Leia o cabeçalho (docstring) do arquivo ou o mapa no README.md.
