💾 Backups do modelo

O treinador também guarda cópias automáticas antes de cada sobrescrita. Fazer backup é simples — recuperar é coisa séria.

🔒 Máximo de 2 backups mantidos (o mais recente de modelo.pt e de modelo_melhor.pt) — backup é para emergência, não para encher o disco.

⚠️ Atenção: recuperar um backup vai SUBSTITUIR seu último modelo (modelo.pt / modelo_melhor.pt) pelos arquivos do backup escolhido. O modelo atual é guardado como pre_restauro_* antes, por segurança.
🪟 Regra: assim como programas do Windows exigem desinstalar antes de reinstalar, não restaure por cima de um estado que você quer preservar — se não tiver certeza, faça um backup antes. A responsabilidade é sua.
